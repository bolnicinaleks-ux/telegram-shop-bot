# Telegram-бот магазин: каталог, корзина, заказы

aiogram 3 · SQLite (aiosqlite) · Docker

## Возможности

**Клиент**
- Каталог по категориям, карточки товаров с фото, листание ◀️ ▶️
- Корзина с кнопками +/−, хранится в базе (не теряется при перезапуске)
- Оформление: имя, телефон (кнопкой или текстом), самовывоз или доставка с адресом, комментарий
- Стоимость доставки и бесплатная доставка от суммы, минимальная сумма заказа
- Сводка с реквизитами оплаты (например, Kaspi) перед подтверждением
- «Мои заказы» со статусами, отмена нового заказа, уведомления о смене статуса

**Администратор**
- Каталог управляется прямо в боте: `/add` — пошаговое добавление товара (категория → название → описание → цена → фото)
- `/products`, `/p ID` — карточка товара с кнопками: цена, наличие, скрыть/показать, удалить
- Заказ приходит карточкой в личку или в рабочую группу (`ORDERS_CHAT_ID`) с кнопками статуса: «Подтверждён / Отправлен / Выполнен / Отменён»
- `/orders [статус]`, `/order ID`, `/export` — CSV для Excel, `/stats` — заказы и выручка за день / 7 / 30 дней, топ товаров

**Надёжность**
- Название и цена фиксируются в заказе: изменения каталога не меняют старые заказы
- Если цена изменилась между сводкой и подтверждением — клиент видит новую сумму и подтверждает ещё раз
- Закончившийся, скрытый или удалённый товар нельзя добавить и оформить
- Заказ и очистка корзины — одна транзакция
- Лимит заказов в час на клиента

## Демо-режим

`DEMO_MODE=1` — для показа заказчикам. Вместо реквизитов оплаты клиент видит «оплачивать ничего не нужно», а после заказа получает копию карточки, которую видит владелец, с рабочими кнопками статуса — только для своего заказа. Управление каталогом, админ-команды и чужие заказы остаются недоступны.

## Запуск

```bash
cp .env.example .env   # заполнить BOT_TOKEN и ADMIN_IDS
```

Docker:
```bash
docker compose up -d --build
```

Без Docker (Python 3.11+):
```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m bot
```

Каталог пуст — напишите боту `/add` с аккаунта администратора.

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | Токен от @BotFather |
| `ADMIN_IDS` | — | ID администраторов через запятую |
| `ORDERS_CHAT_ID` | — | ID рабочей группы (иначе — в личку админам) |
| `SHOP_NAME` | `Магазин` | Название в приветствии |
| `CURRENCY` | `₸` | Валюта |
| `PAYMENT_INFO` | — | Реквизиты оплаты, `\n` — перенос строки |
| `PICKUP_ADDRESS` | — | Адрес самовывоза |
| `DELIVERY_ENABLED` | `1` | `0` — только самовывоз |
| `DELIVERY_PRICE` | `0` | Стоимость доставки |
| `FREE_DELIVERY_FROM` | `0` | Бесплатная доставка от суммы (`0` — нет) |
| `MIN_ORDER` | `0` | Минимальная сумма заказа |
| `MAX_ORDERS_PER_HOUR` | `5` | Лимит заказов в час на клиента |
| `TIMEZONE` | `Asia/Almaty` | Часовой пояс |
| `DEMO_MODE` | `0` | Демо-режим для показа заказчикам |

## Структура

```
bot/
  __main__.py      точка входа, меню команд для клиентов и админов
  config.py        настройки из .env
  db.py            SQLite: категории, товары, корзины, заказы
  delivery.py      отправка и обновление карточек заказов
  keyboards.py     клавиатуры и CallbackData
  states.py        оформление заказа, мастер добавления товара
  utils.py         форматирование, статусы, расчёт сумм
  handlers/
    client.py      каталог, корзина, оформление, «Мои заказы»
    admin.py       управление каталогом и заказами, статистика
tests/test_flow.py сквозной тест без Telegram
```
